# Monkey (Tested on Windows only)

A Zig/Ziglang version [monkey](https://monkeylang.org/) language interpreter. From [Write An Interpreter In Go](https://interpreterbook.com/).

## Zig version

```
// 2026/05/12
0.17.0-dev.263+0add2dfc4
```

## Usage

```
$ zig build run
```
